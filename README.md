# drawIT
Still a work in progress

A web based game, where the game begins with all the players making up a word themselves, and then those words randomly get assigned to players who then have to drawIT turn by turn, while the other players have to guess. Points will be assigned depending on how quickly they guess the word.

Ranked System has been implemented with a leaderboard feature showing top 100 players

First draft of the game has been done
Hosted on an aws EC2 instance
